## P5.1 统计增强（buildStats 扩展 + 统计面板升级）

### buildStats 纯函数扩展（保持向后兼容，新增字段）
- `streak`：连续专注天数（从今天往前数连续 `focusMinutes > 0` 的天数；今天尚无记录则从昨天起算，避免"当天还没专注"清零）
- `prev`：上一周期对照 `{ createdTotal, doneTotal, focusMinutes }`（7/30 天区间整体前移同长度）
- `backlog`：未完成事项积压 `{ overdue（截止日 < 今天）, today（今天到期）, future, undated, urgent（紧急未完成） }`
- `daily` 结构不变（已有 created/done/focusCount/focusMinutes）

### 统计面板（buildStatsPanel）改动
1. **趋势卡加切换**：`专注分钟 / 完成事项` seg 切换（复用同一柱状图，切数据列；状态存模块变量 `statsTrendMode`）
2. **新卡「待办积压」**：逾期 / 今日 / 未来 / 无日期 四格 + 紧急未完成数（逾期 > 0 时红色高亮）
3. **新卡「专注报表」**：区间专注天数、日均分钟、单日最高、连续专注 streak；下方列「今日专注任务」top（pomoTaskLogs 当日数据，无则隐藏该行）
4. **新卡「本周 vs 上周」**：完成事项 / 新增 / 专注分钟 三组 本周值+环比箭头（固定按周，不随 7/30 区间变化；上周基数为 0 时显示"—"）
5. 现有概览/分类/项目排行/周报卡保持不变

## P5.2 自然语言快速添加（parseQuickInput 纯函数 + 实时回填）

### parseQuickInput(text, now) 纯函数
- 返回 `{ title, date, time, hits: [命中的原始片段] }`；未命中 date/time 时对应字段为 `''`
- 日期词表（剥离后标题不得为空，否则整体不解析）：
  - 相对：今天/今晚/明天/后天/大后天/N天后（N 为阿拉伯或中文数字 1~99）
  - 星期：周X/星期X/下周X（取未来最近该日，含今天；「下周」强制 +7）
  - 绝对：X号|X日（本月，已过则下月）、X月X号|X日（年份取未来最近）、MM-DD、YYYY-MM-DD
- 时间词表：
  - `HH:MM`、X点、X点半、X点Y分、X点整
  - 上午X点（原值）、中午12点、下午X点（+12）、晚上X点（≤11 加 12，12 → 0）
  - N小时后 / N分钟后 / 半小时后（相对 now，产生 date+time）
- 解析优先级：先长词后短词、先绝对后相对；全部命中片段从标题剥离并压缩空白

### buildQuickAdd 面板改动
- 输入实时解析：hint 行显示解析预览「→ 10/13(周二) 15:00」；解析出即**回填日期/时间控件**（所见即所得，用户可再改，保持"时间可选"偏好）
- 手动改过控件后继续输入文字不再覆盖控件（仅当本次输入解析结果变化时回填）
- 保存逻辑不变（仍读控件值），回车连续录入习惯保留

## P5.3 事项模板

### 存储
- `localStorage: eventTemplates` = `[{ id, title, time, category, urgency, recur, tags, description, createdAt }]`（日期不入模板，应用时默认今天）
- backup.js `BUSINESS_KEYS` 追加 `'eventTemplates'`（进三档备份；**不进局域网同步快照**，避免动 mergeSyncData 引入风险，注释说明）

### 入口与交互
1. 右键事项菜单（showEventMenu）加「存为模板」：取该事项 title/time/category/urgency/recur/tags/description 存入；已存在的同名字段组合提示去重（同 title+time 视为重复，跳过）
2. 快速添加面板顶部加「模板」chips 行（最多显示 8 个 + 「…」展开）：点击 chip → 预填整表单（标题/时间/分类/紧急度），用户确认后回车保存；chip 右键 → 删除该模板（confirm 确认）
3. 模板为空时该行隐藏（不占空间）

## 明确不做（防范围蔓延）

- 不引入图表库（延续纯 CSS 柱状）
- 不做批量操作增强（已有 batchMode 覆盖改分类/删除等）
- 不做模板字段级编辑器（模板即字段快照，应用后自由修改）
- 自然语言不解析时长/重复规则/项目归属（recur/项目仍走下拉选择）
- 模板不进局域网同步快照（仅三档备份），不为此动 mergeSyncData
- 不做统计页的时间占比估算（事项无时长概念，数据不支持）
