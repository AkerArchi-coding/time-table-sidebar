## P6.1 月历交互补齐（右键 / +N 展开 / 拖拽改期）

### 格子右键菜单
- 格子空白区右键 → 小菜单：「在该日新建事项」（打开顶部编辑表单并预填日期为该日）、「查看该日」（现有跳转周视图行为）
- 事项条右键 → 复用现有 showEventMenu（虚拟事项语义与周视图一致：编辑作用于模板、按日完成等）
- 复用 showItems/positionMenu 基础设施，不新建菜单体系

### +N 展开当日清单
- 点击 `+N` → 该格下方手风琴展开完整当日事项列表（同层展开偏好），再次点击或点别处收起
- 展开列表项点击 → 打开编辑（与格子内事项条同语义）；同时只允许一格展开

### 月历拖拽改期
- 事项条 mousedown 自实现拖拽（沿用 enableWeekDrag 的浮层思路）：拖起半透明 ghost，目标格子高亮，松手 `moveEventToDate`
- 触发阈值：移动 > 6px 才算拖起，避免与点击编辑冲突；Esc 取消
- 虚拟重复事项按模板改期（与右键「调整到哪一天」语义一致）；批量模式/工具层不启用
- 与周视图拖拽共用底层 helper（提取 ghost/高亮公共逻辑，不改周视图行为）

### 验证
- 单测：右键菜单动作映射、+N 展开状态互斥；拖拽逻辑保持 vm 层可测部分（日期换算）覆盖
- node --check → 全量测试 → Electron 冒烟 → commit

## P6.3 性能加固（按日索引缓存 + 派生缓存统一失效）

### 按日事件索引
- 新增 `dayIndex`：Map<dateKey, 当日事项数组>（含重复事项虚拟投影），在 `getEventsByDate` 首次调用时基于 eventsCache 惰性构建
- 月历 42 格 / 周视图 7 卡 / 今日视图 / 甘特 / 统计全部经由 `getEventsByDate` 受益（42 次全量扫描 → 1 次构建 + O(1) 查询）
- 索引存虚拟事件对象引用；读取方不改对象（现有代码均未原地改，实施时复核）

### 派生缓存统一失效
- 新增 `invalidateDerivedCaches()`：同时清空 `eventsCache` 与 `dayIndex`（根治"直写 storage 后忘清缓存"类陷阱）
- `saveEvents` / `recurDoneSet` / 同步合并写回 / 备份导入 全部改走该函数
- recurDoneSet 低频，失效重建成本可忽略

### localStorage 写入失败可见化
- saveEvents/saveProjects 等写失败（配额超限）时 showToast 红条提示一次（节流，避免连续弹）；不写死降级逻辑

### 验证
- 单测：索引与全量扫描结果一致性（含重复投影、跨日事项、recurDone 变化后失效）；invalidateDerivedCaches 覆盖各写入入口
- node --check → 全量测试 → Electron 冒烟 → commit

## P6.4 外部日历订阅（只读 iCal 投影）

### 数据与存储（仅本机）
- `localStorage: calSubscriptions` = `[{ id, name, url, enabled, lastSync, lastError }]`（订阅定义进三档备份 BUSINESS_KEYS；**不进局域网同步快照**，同 eventTemplates 处理，注释说明）
- `localStorage: calSubCache_{id}` = 解析后的事件数组 `[{ uid, title, start, end, time, description }]`（缓存不进备份，刷新即重建）

### 拉取与解析
- 主进程新增 IPC `cal-sub-fetch`：https/http GET 订阅 URL（复用天气的同套 http/https 设施，10s 超时，失败返回错误文案）
- 渲染层复用现有 parseIcs/normalizeIcsEvent 解析；RRULE 重复按现有 rruleToRecur 口径投影；时区不换算（本机浮点，与导出语义一致）

### 面板与展示
- iCal 工具面板（buildIcalImport）扩展为三区块：导入 / 导出 / **订阅**（列表 + 添加 URL + 启用开关 + 手动刷新 + lastSync/lastError 显示；删除需 confirm）
- 周视图/月历渲染时在 `getEventsByDate` 结果后叠加订阅事件：只读样式（斜纹/虚线边 + 订阅色条），点击 → toast 显示标题时间详情（不可编辑、不进右键菜单、不参与统计/批量/同步）
- 自动刷新：每小时一次（窗口存活期 setInterval，失败静默记 lastError）；手动刷新立即生效
- 订阅事件跨日时按日投影（与内部跨日事项同口径）

### 验证
- 单测：订阅定义存取、缓存键命名、只读投影过滤（不进统计/批量）；解析复用现有 ics 测试口径
- 冒烟：面板开关 + 本地起一个 http .ics 源手动刷新（若时间允许，否则纯单测）
- node --check → 全量测试 → Electron 冒烟 → commit

## 明确不做（防范围蔓延）

- 不做月历视图的周数列/年份切换（月份导航已够）
- 子任务不级联完成主事项、不进统计、不支持嵌套
- 索引缓存不做增量维护（写路径统一整体重建，逻辑简单可测）
- 不做渲染时序改造（render 保持同步，不引入 scheduleRender）
- 订阅不做双向同步/CalDAV、不做订阅事件写入本地 events（只读投影）
- 不自定义全局热键录制（沿用现有固定两枚可开关热键）
- 订阅缓存不进三档备份、定义不进局域网同步快照
