## P7.1 回收站与撤销删除

### 数据与存储（仅本机）
- `localStorage: trashEvents` = 事项对象数组（原对象 + `deletedAt` 时间戳），上限 200 条滚动；启动与打开面板时清理超 30 天的条目
- `trashEvents` 追加进 backup.js 的 `BUSINESS_KEYS`（进三档备份）；**不进局域网同步快照**（删除传播仍由墓碑负责，回收站是本地安全网，注释说明）
- 范围：仅事项（含重复模板事件对象）进回收站；项目删除、事项模板删除行为不变（明确不做）

### 删除路径接入
- `deleteEvent` / 批量删除：删除前把事项对象（虚拟 id 先解析为模板，与现语义一致）移入回收站，其余逻辑（墓碑、项目 revision、render）不变
- 项目级联等其它删除路径不动

### 撤销删除
- 新增 `showActionToast(msg, actionLabel, onAction)`：复用现有 .toast 元素（与 showToast/showReminderToast 互斥，同一元素改造），6 秒内可点「撤销」
- 单个删除 → toast「已删除「标题」」+ 撤销按钮；批量删除 → toast「已删除 N 项」+ 撤销（一次性全部恢复）

### 回收站面板
- 设置面板「数据」区新增「回收站」区块：数量角标 + 展开/收起列表（标题、原日期、删除时间）
- 每项操作：恢复 / 彻底删除（confirm）；顶部「清空回收站」（confirm）
- 恢复语义：从回收站移除 → 写回 events 且 `updatedAt` 置为当前时间（晚于墓碑 deletedAt，设备同步不会再删它）→ 清除该 id 本地墓碑 → `bumpProjectRevision` → render
- 彻底删除/清空：仅从回收站移除，不动墓碑

### 验证
- 单测：回收站存取与 200 条滚动上限、30 天过期清理、恢复的 updatedAt/墓碑处理、批量删除撤销恢复、trashEvents 进备份键列表
- node --check → 全量测试 → Electron 冒烟 → commit

## P7.2 自动备份

### 主进程（main.js + preload.js）
- 自动备份目录：主进程数据目录下 `auto-backups/`（与数据目录迁移设施同根，迁移动作一并迁移）
- 新增 IPC：`backup-auto-write`（写入 `tt-auto-YYYYMMDD-HHmmss.json`，超出保留数删除最旧文件，固定保留 7 份）、`backup-auto-list`（文件名+mtime+大小）、`backup-auto-read`（读入并解析）、`backup-auto-open-dir`（shell.openPath；若已有「打开数据目录」类 IPC 则复用不新建）
- preload.js 映射以上四个到 window.timetable

### 渲染层调度
- 设置 `autoBackupEnabled`（默认开）+ `lastAutoBackupAt`（存 appSettings）
- 触发时机：启动时（距上次自动备份 >20 小时则执行）+ 窗口存活期每小时检查一次
- 备份内容：复用 buildBackup('full', ...) 全量口径（经 backup-get-main-files 取主文件）

### 设置面板 UI（数据区）
- 「自动备份」区块：开关、立即备份一次按钮、上次自动备份时间、备份文件列表（按时间倒序，每项「恢复」按钮）
- 恢复：读取文件 → 走现有导入校验与 confirm 流程（完整备份覆盖警告沿用现有文案）

### 验证
- 单测：调度判定纯函数（enabled/间隔 20h/首启无记录）、文件名生成、保留 7 份的滚动删除逻辑（vm 沙箱模拟 fs 数组）
- 冒烟：启动后 auto-backups 目录生成
- node --check → 全量测试 → Electron 冒烟 → commit

## P7.3 提醒增强

### 贪睡时长可选
- 提醒 toast 的「稍后 5 分钟」单按钮 → 三枚：稍后 5 / 10 / 30 分钟（写入 `snoozeUntil` 逻辑不变，按所选分钟）
- 「完成」按钮保持不变

### 重复提醒（未处理时再次提醒）
- 设置 `remindRepeatMin`：0（默认，不重复）/ 10 / 30 分钟，设置面板「提醒」区新增下拉
- `remindedKeys` 存储结构扩展：`{date, ids}` → `{date, ids, ts, stop}`（ts: key→上次提醒时间戳；stop: Set，用户已点「不再提醒」的 key）；旧结构无 ts/stop 字段兼容
- 轮询逻辑新增：key 已提醒 && 未完成 && 未点不再提醒 && 事件未过结束时间 && 距上次提醒 ≥ remindRepeatMin → 再次弹 toast+响铃+系统通知（复用现有链路），刷新 ts
- toast 新增「不再提醒」按钮：加入 stop 集合并持久化

### 默认提前量
- 设置 `remindAheadDefault`：0（默认）/ 5 / 10 / 15 / 30 分钟；设置面板「提醒」区下拉
- 新建事项表单 `.ev-remind` 初始值取该设置（已有事项的 remindAhead 字段值优先，normEvent 默认保持 0，旧数据零迁移）

### 验证
- 单测：再提醒判定纯函数（各条件组合）、remindedKeys 新旧结构兼容、贪睡分钟写入、默认提前量读取与表单初值
- node --check → 全量测试 → Electron 冒烟 → commit

## P7.4 应用内键盘快捷键与帮助面板

### 快捷键绑定
- document 捕获阶段全局 keydown；跳过条件：焦点在 input/textarea/select/contenteditable、输入法 composing 中、按着 Ctrl/Alt/Meta（Ctrl+F 除外）
- 绑定清单：
  - `Ctrl+F` → 打开搜索工具并聚焦输入框
  - `N` → 打开新建事项表单（复用现有新建入口）
  - `1` / `2` / `3` / `4` → 今日 / 周 / 月 / 甘特视图
  - `←` / `→` → 当前视图周期翻页（复用现有前后导航处理）
  - `Esc` → 逐层关闭：编辑表单 > 工具面板 > 弹出菜单
  - `?`（Shift+/）→ 快捷键帮助浮层

### 帮助浮层
- 固定定位遮罩 + 卡片，列出全部快捷键分组（视图 / 事项 / 通用）；Esc、点击遮罩或关闭按钮关闭
- styles.css 新增 `.kbd-help-*` 样式；无新依赖

### 验证
- 单测：目标可编辑判定纯函数、按键映射纯函数（含 composing/修饰键排除）
- 冒烟重点：表单内打字不触发 N/1、Esc 逐层关闭不误伤提醒 toast
- node --check → 全量测试 → Electron 冒烟 → commit

## 明确不做（防范围蔓延）

- 项目删除、事项模板删除不进回收站（仅事项；行为保持现状）
- 回收站不进局域网同步快照；同步删除传播仍以墓碑为准
- 自动备份不做增量/压缩/加密，固定保留最近 7 份，不做云上传
- 不自定义快捷键录制（固定键位 + 帮助面板）；不覆盖全局热键（Ctrl+Alt+*）
- 热力图不做年份切换（固定近一年滚动窗口）、不做按项目/分类过滤
- 重复提醒不做逐事项单独配置（仅全局开关 + 间隔）
