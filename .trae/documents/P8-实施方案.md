# P8 实施方案：项目阶段层级 + 每日工作记录 + 番茄钟自动开始 + 番茄钟音效开关

> 来源：10 月 10 日 TRAE V3 架构审查中规划但 P1~P7 未实现的 4 项功能。
> 约束（沿用 P1~P7）：增量开发不推翻现有架构；现有功能不受影响；数据仅存本机；零新增 npm 依赖；代码注释中文；每批独立 commit + 测试通过再进下一批；方案获批后才写代码。

## P8.1 项目阶段层级（Phase）

### 数据模型（兼容迁移）
- `Project` 新增 `phases` 字段：`[{id, name, order}]`，无此字段时迁移为 `[]`
- `Event` 新增 `phaseId` 字段（可选字符串），无此字段时迁移为 `''`（归为"未分阶段"）
- `phases` 追加进 `backup.js` 的 `BUSINESS_KEYS`（随 projects/events 整体备份，无需单独 key）
- 不进局域网同步快照的额外改动：phaseId 随 events 同步，phases 随 projects 同步（复用现有墓碑/合并机制）

### UI
- **项目详情面板**（accordion 展开后）：在项目信息卡下方新增「阶段」区块：
  - 阶段列表（名称 + 事项数 + 拖拽排序，简化为上移/下移按钮）
  - 「+ 添加阶段」按钮
  - 每个阶段行内：重命名（点击编辑）、删除（confirm，删除后该阶段事项 phaseId 置空）
- **事项表单**（新建/编辑）：在项目下拉后新增「阶段」下拉，选项随所选项目动态加载（未选项目时隐藏）
- **项目甘特图**：事项条左侧显示阶段名称小标签（有 phaseId 时）；可选按阶段分组（默认不分组，保持现有布局）
- **项目事项列表**：事项卡片显示阶段标签

### 验证
- 单测：loadProjects 迁移 phases 字段、loadEvents 迁移 phaseId、阶段增删改纯函数、删除阶段时事项 phaseId 清空
- 冒烟：项目详情阶段增删改、事项表单阶段联动、甘特图阶段标签

## P8.2 每日工作记录

### 数据来源（纯派生，不新增存储）
- 复用 `buildStats(events, pomoHistory, 1, date)` 的 daily 数据：某日完成事项数、专注次数、专注分钟
- 完成事项清单：`events.filter(e => e.done && isoDateKey(e.updatedAt || e.createdAt) === dateKey)`
- 专注事项明细：`pomoTaskLogs`（当日）+ `pomoHistory`（跨天聚合）

### UI
- **统计面板**新增「每日工作记录」区块（在趋势卡之后）：
  - 日期选择器（默认今天，可往前翻）
  - 当日概览：完成事项数 / 专注次数 / 专注分钟
  - 完成事项清单（标题 + 时间 + 项目）
  - 空状态提示
- 不新增独立工具面板，复用统计面板结构

### 验证
- 单测：buildDailyWorkRecord(events, pomoHistory, date) 纯函数（空数据、跨日、无完成事项）
- 冒烟：统计面板翻页查看历史日期的工作记录

## P8.3 番茄钟自动开始开关

### 数据
- `pomoCfg` 新增 `autoStart: false`（默认关闭，不改变现有行为）
- `loadPomoCfg` 读取并兜底，`savePomoCfg` 持久化

### 逻辑
- 番茄钟面板（`.pomo-row` 后）新增「休息后自动开始专注」开关
- 休息阶段结束时（`pomoTick` 内 `POMO.mode === 'break'` 分支末尾）：
  - 若 `POMO.autoStart` 为 true → 自动调用 `pomoStart()` 开启下一个专注
  - 否则保持现有行为（`POMO.running = false`，等待手动开始）

### 验证
- 单测：pomoCfg 持久化 autoStart 字段、休息结束时 autoStart=true 自动开启 / false 保持暂停
- 冒烟：开关切换后休息结束行为符合预期

## P8.4 番茄钟音效开关

### 数据
- `pomoCfg` 新增 `soundEnabled: true`（默认开启，不改变现有行为）
- `loadPomoCfg` 读取并兜底，`savePomoCfg` 持久化

### 逻辑
- 番茄钟面板新增「音效」开关
- `playChime(pattern)` 入口处检查：若 `!POMO.soundEnabled` 直接 return（不播放音效，但系统通知不受影响）
- 提醒音效（`CHIME.remind`）不受此开关影响（提醒是独立功能，保持现有行为）

### 验证
- 单测：pomoCfg 持久化 soundEnabled 字段、playChime 在 soundEnabled=false 时不创建 AudioContext
- 冒烟：开关关闭后番茄钟阶段切换无声，开启后恢复

## 明确不做（防范围蔓延）

- 阶段不做进度/完成率自动计算（仅作为事项分组标签）
- 阶段不做颜色/图标自定义
- 每日工作记录不做编辑/导出（只读查看）
- 番茄钟不做自定义音效上传（仅开关）
- 番茄钟自动开始不做"专注→休息"的开关（工作结束自动休息保持现状）
